
# Netcode for Entities

Netcode for Entities is a networking framework built on top of Unity’s Entity Component System (ECS) that allows you to create multiplayer games with server authoritative architecture and client prediction.

Refer to the [Unity Netcode Samples](https://github.com/Unity-Technologies/EntityComponentSystemSamples/tree/master/NetcodeSamples) for introductory step-by-step samples, material, and some more advanced demos.

![](images/entities-splash-image.png)

## Requirements

Netcode for Entities requires Unity version 6.7.

Install Netcode for Entities via the Package Manager in the Unity Editor:

1. Navigate to **Window** > **Package Management** > **Package Manager**.
2. Click the plus icon in the top-left of the **Package Manager** window and select **Install package by technical name...** from the drop-down menu.
3. Enter `com.unity.netcode` into the **Technical name** field and click **Install**.

### Dependencies

Netcode for Entities depends on [Unity Transport](https://docs.unity3d.com/Packages/com.unity.transport@latest) and [Unity Entities](https://docs.unity3d.com/Packages/com.unity.entities@latest), which are both installed with the Editor by default.
